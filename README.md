# MYOU网络情报分析师

> 免费全网情报工具：填入关注点 → 自动建监测 → 定时采集 → 调研 + 预警 + 策略。
>
> 📍 官网（含案例与使用说明）：**https://myou.dxtools.top**
> 📦 项目地址：**https://github.com/modayishujia/myou-data-research**

一份可直接装进 AI 助手的**调研方法论 skill**（纯 markdown，无脚本、无服务端、无订阅、无账号）。适合市场/公关负责人、品牌方、内容与运营团队，用来做：舆情监控、行业调研、产品发布追踪、投资研究、金融单品追踪。

- **全网采集**：公众号 / 小红书 / 微博 / 新闻 / 抖音 / X / Reddit 的提及与评论区，含传播链路（首发 → 转发 → 大 V 参与）与树状讨论
- **数据源随话题动态匹配**：国内大众话题侧重小红书/抖音，出海与技术话题侧重 X/Reddit，主源失败自动用备选源补齐
- **不设固定套路**：每轮先盘点实际采到的数据，再单独生成该轮分析逻辑（8 维度只是候选池，指标基准按话题自校准）
- **数据本地化**：纯 markdown 增量沉淀，无数据库、无云端，历史不覆盖，可随时打开编辑

## 🚀 快速开始

### 1. 安装（对你的 AI 助手说一句话）

```
安装这个 skill https://github.com/modayishujia/myou-data-research.git
```

支持技能（Skills）系统的 AI 助手均可（Claude Code、WorkBuddy 等）；也可以直接把本仓库文件夹放进助手的技能目录（如 `~/.claude/skills/`、`~/.workbuddy/skills/`）。

### 2. 使用（说人话就行）

```
/myou-data-research 调研一下理想汽车的舆情，看看传播效率和触达人群，发现一些破圈点
```

自然语言触发，无需记住命令。触发词：调研、追踪、舆情、发酵、演变、监控、采集、research。

**场景预设**：舆情监控（默认）· 行业调研 · 产品发布 · 投资研究 · 金融单品追踪

## 🛠 能力一览

| 能力 | 说明 |
|------|------|
| 📡 全网提及采集 | 公众号/小红书/微博/新闻/抖音/X/Reddit，每源必采评论区并总结；浏览器控制工具（如 Kimi WebBridge）优先，降级 websearch/webfetch 并标注 |
| 🎯 数据源动态选择 | 按话题信号匹配首选源（见下方表），演变可换主源，主源失败用备选源补齐 |
| 🧠 每轮专属分析 | 数据盘点 → 生成本轮分析逻辑 → 执行；8 维度为候选池，可自定义维度；样本量透明、阈值按话题基线自校准 |
| 🚨 分级预警 | 声量突增/负面占比/新关键词/KOL 负面/情感转向等，红橙黄蓝分级；输出结构化告警（指标+证据+SLA+建议），可接企业微信/飞书 Webhook |
| 📄 报告三层 | 一页摘要（决策者）/ 标准报告（执行）/ 危机快报（10 分钟），每轮自动生成「vs 上轮」变化 |
| 🛟 危机处置闭环 | 预警 → 危机快报 → 处置建议（含对外口径）→ 预案库沉淀 → 72h 复盘更新预案 |
| ⚖️ 竞品对标 | 本品 vs 竞品声量份额（SoV）、情感与 KOL 指标横向对比 |
| 🔭 持续循环 | 按话题阶段自动匹配观测频率（发布前 30 天/7 天/当天/后 7 天/后 30 天） |

### 数据源动态选择参考

| 话题信号 | 首选源 | 辅助源 |
|----------|--------|--------|
| 国内大众消费/品牌口碑/产品发布 | 小红书、抖音 | 微博、公众号、新闻 |
| 出海品牌/海外市场/全球事件/海外首发 | X、Reddit | 新闻 |
| 技术/开发者/开源/AI/加密货币 | Reddit、X | 新闻 |
| 金融/上市公司/交易 | 新闻、雪球/东财 | X |
| 泛文化/影视/游戏/热点事件 | 微博、抖音 | X、新闻 |
| 争议/全球政策事件 | 新闻、X | Reddit |

### 每轮产出

- **一页摘要**：当前态势 / 本轮关键变化 / 预警 / 建议
- **标准报告**：本轮分析逻辑 / 本轮变化 / 核心发现 / 证据 / 解读 / 建议 / 各平台评论区总结 / 风险矩阵 / 预测
- **危机快报**：事件 / 证据 / 影响 / 处置建议 / 对外口径（红橙预警时自动输出）

## 💾 数据存储

数据以纯 markdown 增量写入 `~/.local/share/data-research/{topic-id}/research.md`，每次采集追加写入、历史不覆盖；每个话题在初始化时单独生成一套可改写的调研方法论，「## 预警记录」「## 预案库」章节随运行累积。
