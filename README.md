# Data Research Skill

全天候数据采集 → 增量存储 → 多维度分析 → 问题发现 → 自动刷新监控看板。

## 这是什么

一个通用的数据调研 skill，适用于任何 AI Agent 平台。自动从网络和社交媒体采集数据，分析话题演变趋势，发现关键信号和异常，并通过本地看板实时展示。

**适用场景**：舆情监控、行业调研、产品发布追踪、投资研究、竞品分析。

## 安装

对你正在使用的 AI Agent（Codex / MiMoCode / Claude Code / Cursor / Kimi Code 等）说：

> **帮我从：https://github.com/modayishujia/myou-data-research 安装数据调研工具**

Agent 会自动完成安装（克隆仓库到你的 skill 目录 + 安装看板依赖），无需手动敲命令。

## 使用

### 触发方式

自然语言触发，无需特殊命令：

- "调研XX"
- "帮我看看XX的舆情"
- "追踪XX事件变化"
- "XX话题发酵过程"
- "帮我收集XX的信息"
- "生成XX的深度报告"（触发 14 章节完整版报告）

### 场景自动匹配

系统根据话题内容自动匹配分析场景：

| 场景 | 触发词 | 分析链路 |
|------|--------|----------|
| 投资研究 | 股票/投资/估值/财报 | 上市公司→大单品→评论→意图→市场认知→投资判断 |
| 产品发布 | 发布/新品/上市/交付 | 产品→主内容+评论→意图→市场认知→传播策略 |
| 行业调研 | 行业/赛道/市场/趋势 | 行业→市场数据→竞争格局→趋势判断→机会识别 |
| 舆情监控 | 舆情/口碑/评价/争议 | 品牌→情感追踪→危机预警→叙事分析→应对建议 |

## 核心能力

### 数据采集
- **网页搜索**：新闻报道、行业分析、研报摘要
- **小红书**：笔记内容、评论区、搜索热点（通过浏览器自动化）
- **抖音**：视频数据、评论区、搜索标签（通过浏览器自动化）
- **评论区深度分析**：每个平台的评论区都必须采集并生成总结

### 分析引擎
- **8维度框架**：搜索热度/内容生态/评论区情绪/KOL画像/竞品对比/话题发酵/风险评估/预测研判
- **时间对比引擎**：每次采集自动与上次对比，计算数据量/情感/关键词变化
- **异常检测**：情感急转、量级异常、关键词涌现自动识别
- **场景自适应**：根据话题类型自动调整分析深度和侧重点

### 监控看板
- 暗色全屏大屏，上下自由滚动
- 关键发现卡片（严重/高风险/中等/洞察）
- 态势判断 + Delta 对比（数据变化/信号变化/情感变化/趋势）
- 异常检测告警面板
- 风险预警（三级计数 + 详情 + 行动建议）
- 各平台评论区洞察（摘要 + 全屏弹窗完整分析）
- 信号与建议
- D3.js 时间趋势图表
- 演变时间线
- 数据条目表格（平台发布时间排序）
- 30分钟自动轮询刷新
- ESC / × 关闭弹窗

### 深度报告（可汇报）
- **14 章节数据驱动报告**：核心结论 / 情绪全景 / 正负面深度分析 / 来源追溯 / 操纵判断 / KOL 画像 / 竞品对比 / 风险矩阵 / 预测研判 / 行动建议 / 演变时间线 / 评论区洞察 / 数据明细
- 内容随数据动态定制：有数据的章节渲染、无数据自动隐藏
- 看板顶栏「📊 报告」入口，每次采集后自动更新
- 支持 PDF 导出

### 多话题总览
首页显示所有调研话题的健康状态（绿/黄/红灯），点击进入单话题详情。

## 数据存储

数据存储在 `~/.local/share/data-research/` 目录下：

```
~/.local/share/data-research/
└── {topic-id}/
    ├── meta.json       # 话题元数据
    ├── entries.json    # 数据条目
    ├── evolution.json  # 演变节点
    ├── signals.json    # 信号洞察
    └── snapshots.json  # 快照（用于 Delta 对比）
```

## API

启动看板后：

| 端点 | 说明 |
|------|------|
| `GET /` | 多话题总览 |
| `GET /topic/{id}` | 单话题详情看板 |
| `GET /topic/{id}/report` | 深度报告（缺失时自动生成） |
| `GET /api/topic/{id}` | JSON API |
| `GET /api/topics` | 所有话题列表 |
| `GET/POST /api/report/{id}` | 重新生成深度报告 |
| `GET /api/export/{id}` | 导出 PDF 报告 |
| `GET /api/collect/{id}` | 触发采集（采集后自动更新报告） |
| `GET /assets/{file}` | 静态资源 |
