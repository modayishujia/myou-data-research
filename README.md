# MYOU网络情报分析师 Skill

一个纯方法论的调研 skill：定义如何采集网络与社媒数据、如何用 8 维度框架分析问题、如何追踪话题在时间维度的发酵与演变，并产出可直接用于汇报的文字化深度报告。本 skill 不依赖任何脚本或网页服务，所有分析与报告由模型按 SKILL.md 直接执行。

**适用场景**：舆情监控、行业调研、产品发布追踪、投资研究、金融单品追踪。

## 触发方式

自然语言触发，无需特殊命令：

- "调研 XX"
- "帮我看看 XX 的舆情"
- "追踪 XX 事件变化"
- "XX 话题发酵过程"
- "帮我收集 XX 的信息"

## 核心方法

### 数据采集
- **网页搜索**：新闻报道、行业分析、公众号文章
- **小红书**：笔记内容、评论区、搜索热点（浏览器控制工具/自动化）
- **抖音/微博/X**：内容、评论区、热搜/话题页、传播路径（浏览器控制工具优先，降级 websearch）
- **评论区深度分析**：每个平台的评论区都必须采集并生成总结

### 分析框架
- **每轮专属分析逻辑**：先盘点本轮数据，再单独生成分析方案；8 维度只是候选池，可自定义维度，不设固定套路
- **8 维度候选池**：搜索热度 / 内容生态 / 评论区情绪 / KOL 画像 / 竞品对比 / 话题发酵 / 风险评估 / 预测研判
- **KMI 参考指标库**：正面情绪占比、负面情绪占比、价格焦虑指数、疲劳指数、KOL 正面率、竞品对比负面率（首轮为参考阈值，之后按话题基线自校准）
- **场景自适应**：根据话题类型自动调整分析深度与侧重点（投资研究 / 产品舆情 / 行业调研 / 舆情监控 / 金融单品追踪）

### 报告标准
标准化深度报告章节：核心发现 / 发现了什么 / 意味着什么 / 建议怎么做 / 各平台评论区总结 / 信号与建议 / 竞品对比 / 叙事主导权 / 风险矩阵 / 热点发酵预测 / 数据附录。以文字为主体，无数据的模块自动省略。

## 目录结构

├── references/

## 数据存储

数据以纯 markdown 存储在 `~/.local/share/data-research/{topic-id}/research.md`，每次采集追加写入，旧数据不覆盖；每个话题单独生成一套可改写的调研方法论。
