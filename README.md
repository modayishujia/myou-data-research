# MYOU网络情报分析师

> 免费全网情报方法论 skill：填入关注点 → 建监测 → 增量采集 → 调研 + 预警 + 策略。
>
> 📍 官网（案例与说明）：**https://myou.dxtools.top**  
> 📦 项目地址：**https://github.com/modayishujia/myou-data-research**

纯 markdown，无脚本、无服务端、无订阅。适合市场/公关、品牌、内容与运营团队：舆情监控、行业调研、产品发布追踪、投资研究、金融单品追踪。

- **全网采集**：公众号 / 小红书 / 微博 / 新闻 / 抖音 / X / Reddit，每源评论区分层抽样并总结  
- **数据源随话题动态匹配**，主源失败降级并标注缺口  
- **每轮盘点后再分析**：8 维度只是候选池，指标按话题自校准

## 快速开始

### 1. 安装

```
安装这个 skill https://github.com/modayishujia/myou-data-research.git
```

支持 Skills 系统的助手均可；也可将本文件夹放入助手技能目录（如 `~/.claude/skills/`）。

### 2. 使用

```
/myou-data-research 调研一下「话题」，关注情感演变和关键转折点
```

自然语言即可。触发词：调研、追踪、舆情、监控、采集、research。

**场景**：舆情监控（默认）· 行业调研 · 产品发布 · 投资研究 · 金融单品追踪

## 能力一览

| 能力 | 说明 |
|------|------|
| 全网提及采集 | 浏览器工具优先，降级搜索/抓取并标注；评论区分层抽样（可执行预算，非千级硬性指标） |
| 数据源动态选择 | 按话题匹配首选源，演变可换主源 |
| 每轮专属分析 | 盘点 → 分析逻辑 → 执行；样本量透明 |
| 分级预警 | 红/橙/黄/蓝结构化输出；**skill 不负责推送**（Webhook/IM 由宿主处理） |
| 报告三层 | 一页摘要 / 标准报告 / 危机快报，含「vs 上轮」变化 |
| 危机闭环 | 预警 → 快报 → 预案库 → 72h 复盘 |
| 竞品对标 | SoV 与指标横向对比；无数据不编造 |
| 持续循环 | 频率由监测方案与场景默认档驱动 |

## 数据存储

`~/.local/share/data-research/{topic_id}/research.md`：front matter + 话题摘要 + 方法论 + 数据条目 + 演变 + 信号 + 预警记录 + 预案库。  
每轮只追加数据区；读历史优先摘要与最近演变节点。文件过大时切片到 `archive/`。完整规范见 `references/templates.md`。
