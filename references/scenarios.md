# 场景预设

从用户自然语言识别场景，默认「舆情监控」。章节序号 = 匹配优先级（数字小的优先命中）。

## 匹配规则

| 序 | 场景 id | 命中词示例 |
|----|---------|------------|
| 1 | 金融单品追踪 | 单品追踪、热品、交易机会、标的、建仓、股价背离、交付量、销量追踪、个股追踪 |
| 2 | 投资研究 | 股票、投资、估值、财报、业绩、基金、股价、市值、持仓、证券、上市公司 |
| 3 | 产品发布 | 发布、新品、上市、首发、预售、交付、提车、开售、发布会 |
| 4 | 行业调研 | 行业、赛道、市场、趋势、产业、政策、技术演进 |
| 5 | 舆情监控 | 舆情、口碑、评价、争议、品牌、事件（默认） |

`scenario` 字段写入 research.md front matter，与下列章节名一一对应。

---

## 1. 金融单品追踪

**目标**：持续追踪企业单一产品，横向比较同公司热品，发现潜在交易机会线索（不构成投资建议）。

**实体字段**：见 `templates.md` front matter `financial` 段。

**链路**：单品声量/情绪 → 同公司热品排名 → 股价背离检测 → 催化剂 → 机会评分线索

| 阶段 | 采集 | 输出 |
|------|------|------|
| 单品势能 | 声量/情绪/口碑/互动 | 健康度+热度分(0-100) |
| 热品排名 | 同公司多单品 | 热品榜 |
| 股价背离 | 区间涨跌 vs 单品动量 | 背离信号 |
| 催化剂 | 发布/交付/财报/大单 | 催化剂日历 |
| 机会线索 | 信号+背离+催化剂 | 评分/方向/触发/风险 |

**关键词矩阵（占位）**：

- L1 公司名、代码
- L2 单品名
- L3 业务线词
- L4 金融词（交付量、销量、估值、背离）
- L5 催化剂词

**默认频率档**：交付/发布会窗口 daily；平静期 weekly。

**金融数据约定**：同「投资研究」。

---

## 2. 投资研究

**目标**：发现上市公司相关机会与风险（不构成投资建议）。

**链路**：上市公司 → 核心业务/单品 → 社交评论 → 意图 → 市场认知 → 判断 → 策略线索

| 阶段 | 采集 | 输出 |
|------|------|------|
| 公司 | 基本面、公告、股价异动 | 公司概况 |
| 核心业务 | 主要产品/业务线表现 | 业务矩阵 |
| 社交评论 | 社媒+雪球/东财等（websearch） | 评论区总结 |
| 意图 | 买入/观望/卖出/质疑 | 意图分布 |
| 市场认知 | 主流叙事框架 | 叙事分析 |
| 判断与线索 | 机会/风险信号 | 信号与策略线索 |

**关键词矩阵（占位）**：

- L1 公司名、代码
- L2 核心产品/业务
- L3 竞品公司
- L4 财务词
- L5 市场词（估值、评级、持仓）

**默认频率档**：财报/重大公告前后 daily；其余 weekly。

**金融数据约定**：股价/估值/交付量等由采集阶段经 websearch（或宿主提供的金融数据工具）写入 `meta.financial` 时点字段；缺失时降级为「社媒信号」并标注缺口，**不臆造数字**。

## 3. 产品发布

**目标**：发现产品的市场反馈、购买意图与传播机会。

**链路**：产品 → 主内容+评论区 → 意图分析 → 市场认知 → 传播策略

| 阶段 | 采集 | 输出 |
|------|------|------|
| 产品定位 | 卖点、目标用户、价格带 | 产品画像 |
| 主内容 | KOL 评测、媒体、UGC | 内容生态 |
| 评论区 | 各源评论（分层抽样） | 评论区总结 |
| 意图分析 | 必买/观望/放弃/对比 | 意图分布 |
| 市场认知 | 好评点/槽点/盲区 | 认知地图 |
| 传播策略 | 基于证据 | 策略输出 |

**关键词矩阵（占位）**：

- L1 产品名、品牌名
- L2 配置/功能/场景/外观词
- L3 竞品词
- L4 决策词（价格、值不值、优缺点、口碑）
- L5 KOL 词

**默认频率档**（相对发布日 D）：

| 窗口 | 频率 | 重点 |
|------|------|------|
| D-30 | weekly | 热度、内容生态、KOL |
| D-7 | daily | 情绪、竞品、疲劳 |
| D 当天 | hourly | 价格/情绪/顶流反应 |
| D+7 | daily | 口碑、对比、UGC |
| D+30 | weekly | 长尾与生态 |

## 4. 行业调研

**目标**：发现行业趋势与竞争格局变化。

**链路**：行业/赛道 → 市场数据 → 竞争格局 → 趋势判断 → 机会识别

| 阶段 | 采集 | 输出 |
|------|------|------|
| 行业概况 | 规模、增速、政策 | 行业画像 |
| 市场数据 | 融资/IPO/并购/出海等 | 事件时间线 |
| 竞争格局 | 头部玩家、差异化 | 竞争分析 |
| 趋势判断 | 技术/资本/政策 | 趋势信号 |
| 机会识别 | 投资或业务机会 | 机会输出 |

**关键词矩阵（占位）**：

- L1 行业名、赛道名
- L2 技术词
- L3 代表公司/产品
- L4 资本与市场词（融资、IPO、出海）
- L5 政策词

**默认频率档**：weekly；重大政策/融资事件日 daily。

---

## 5. 舆情监控（默认）

**目标**：发现品牌/事件的舆情风险与传播机会。

**链路**：品牌/事件 → 情感追踪 → 危机预警 → 叙事分析 → 应对建议

| 阶段 | 采集 | 输出 |
|------|------|------|
| 品牌画像 | 认知、美誉、核心叙事 | 品牌概况 |
| 情感追踪 | 各平台情感分布与变化 | 情感趋势 |
| 危机预警 | 负面萌芽、扩散风险 | 预警信号 |
| 叙事分析 | 品牌/KOL/用户三方 | 叙事格局 |
| 应对建议 | 基于证据 | 策略输出 |

**关键词矩阵（占位）**：

- L1 品牌名、产品名
- L2 关联词（创始人、代言人、母公司、子品牌）
- L3 情感词（好评、差评、争议、翻车）
- L4 事件词（发布会、事故、召回、涨价）
- L5 竞品词

**默认频率档**：日常 daily；事件窗口 hourly 或实时。

---

## 通用输出约束

- 先做本轮数据盘点，再选维度；禁止机械套用满 8 维。
- 空模块省略。
- 投资/金融场景结论须带数据缺口与不确定性声明。
