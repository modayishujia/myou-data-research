## KMI（关键监测指标）详细计算

### 正面情绪占比
- **公式**: 正面评论数 / 总采样评论数
- **健康**: >70%
- **预警**: <50%
- **正面判定**: 包含"期待"类关键词（等不及/必买/心动/冲/太香了/绝了）

### 负面情绪占比
- **公式**: 负面评论数 / 总采样评论数
- **健康**: <15%
- **预警**: >25%
- **负面判定**: 包含"负面"类关键词（割韭菜/不值/太贵/失望/不如买XX）

### 价格焦虑指数
- **公式**: 价格相关负面评论 / 总价格评论
- **健康**: <30%
- **预警**: >50%
- **价格评论识别**: 包含"价格/多少钱/贵/便宜/值不值/性价比"等关键词

### 疲劳指数
- **公式**: "挤牙膏/什么时候"类评论的增长率
- **健康**: 稳定或下降
- **预警**: 连续3天增长
- **疲劳词**: 挤牙膏/什么时候/还不发布/等太久了/遛粉

### KOL正面率
- **公式**: 正面KOL数 / 已发声KOL总数
- **健康**: >70%
- **预警**: <50%
- **判定**: KOL发布的内容整体态度为正面

### 竞品对比负面率
- **公式**: 竞品对比中"竞品更好"的占比
- **健康**: <30%
- **预警**: >50%
- **判定**: 对比讨论中用户倾向竞品的比例

## 风险评估矩阵

| 评估维度 | 问题 | 输出 |
|----------|------|------|
| 概率评估 | 该风险发生的可能性有多大？ | 高/中/低 |
| 影响评估 | 若发生，对品牌的影响有多大？ | 极高/高/中/低 |
| 触发条件 | 什么情况下会触发该风险？ | 具体触发条件描述 |
| 预警指标 | 如何提前监测到风险信号？ | 可量化的监测指标 |
| 应对预案 | 风险发生后如何应对？ | 响应时间+应对措施 |
| 跟踪频率 | 多久监测一次？ | 每日/每12小时/每小时 |

## 预测框架

| 预测类型 | 方法 | 输出格式 |

## 抖音搜索热度分析要点

- **搜索结果密度**: 搜索某关键词返回的视频数量和质量 → 密度高=话题热度高
- **头部视频互动**: 搜索结果前10条视频的点赞/评论/分享 → 互动量级反映用户参与深度
- **相关搜索词**: 搜索结果页底部的推荐搜索词 → 反映用户延伸需求
- **筛选标签**: 搜索结果页的筛选维度 → 反映用户关注维度的优先级排序
- **AI推荐摘要**: 抖音AI生成的搜索摘要 → 反映平台算法对内容的理解和聚合方向

## kimi-webbridge 抓取实战指南

### 小红书

**搜索页结构**：
- 笔记卡片：`section.note-item` 或 `[data-v-a264b0de]` 或 `.feeds-page section`
- 每个卡片的 `innerText` 包含：标题、作者、时间、赞数

**提取笔记列表**（evaluate）：
```javascript
(() => {
  const items = document.querySelectorAll("section.note-item, [data-v-a264b0de], .feeds-page section");
  const results = [];
  items.forEach((item, i) => {
    if(i >= 20) return;
    const allText = item.innerText;
    results.push(allText.substring(0, 200));
  });
  return JSON.stringify({count: items.length, samples: results.slice(0, 15)});
})()
```

**提取评论**：
```javascript
(() => {
  const comments = document.querySelectorAll("[class*=comment], .comment-item");
  const results = [];
  comments.forEach((c, i) => {
    if(i >= 15) return;
    const text = c.innerText?.trim();
    if(text && text.length > 5 && text.length < 300) results.push(text);
  });
  return JSON.stringify({commentCount: results.length, comments: results});
})()
```

### 抖音

**搜索结果用 `snapshot` 获取无障碍树效果更好**

**提取视频列表**（evaluate）：
```javascript
(() => {
  const cards = document.querySelectorAll("[class*=video], [class*=card], li[class*=result]");
  const results = [];
  cards.forEach((c, i) => {
    if(i >= 15) return;
    results.push(c.innerText?.substring(0, 200));
  });
  return JSON.stringify(results.filter(r => r && r.length > 10));
})()
```

## 信号与建议框架

每轮分析输出信号，每个信号带建议，按严重度排列：

```markdown

| 严重度 | 信号类型 | 发现 | 建议 |
|--------|----------|------|------|
| 严重 | 热度飙升 | 具体发现描述 | 具体建议 |
| 高风险 | 情感转向 | 具体发现描述 | 具体建议 |
| 中等 | 关键词涌现 | 具体发现描述 | 具体建议 |
```

### 信号严重度定义

| 级别 | 含义 | 响应时间 | 示例 |
|------|------|----------|------|
| 严重 | 需要立即关注，不处理会有实质损失 | 当天 | 负面舆情爆发、数据异常、重大风险事件 |
| 高风险 | 需要持续监控，可能升级 | 1-3天 | 情感转向、叙事变化、竞品动态 |
| 中等 | 值得关注，暂不需行动 | 持续 | 关键词涌现、趋势变化、潜在风险萌芽 |
| 低 | 信息记录，无需行动 | 记录 | 常规数据变化、已知趋势延续 |

## 看板顶部三栏关键总结

看板顶部三个指标卡片，展示分析性内容而非统计数字：

| 卡片 | 内容来源 | 展示要求 |
|------|----------|----------|
| **关键发现** | 评论区总结/信号数据 | 展示最重要的发现，如「百度新闻有争议：高频关键词出海(156次)、ADC(128次)...」 |
| **态势判断** | 演变数据 | 当前阶段 + 最新演变摘要，如「增长阶段 · 创新药出海进入爆发期...」 |
| **风险预警** | 信号数据 | 严重/高风险信号数 + 最需关注的信号描述 |

**禁止展示**：采集条数统计（如「小红书 8条 · 抖音 6条」）、采集方式说明等无分析价值的内容。
