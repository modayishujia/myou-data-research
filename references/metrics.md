# 指标、分类与标签

KMI 计算、情绪/KOL 分类、风险与预测框架、中文标签映射。阈值均为**首轮参考**，第 2 轮起改用话题自身历史基线（环比为主）。

## 分层抽样标准（可执行）

硬约束，避免「Top10 × 50–100 条」导致单轮不可完成：

| 项 | 标准 |
|----|------|
| 主内容 | 每平台 Top 5–10（按互动量，兼顾最新与争议帖） |
| 每内容评论 | 15–30 条：优先高赞 10 + 最新 5 + 争议/低赞有信息量 5 |
| 全平台单轮评论总量目标 | 80–200 条（平台数 × 内容数可调） |
| 深采触发 | 某条内容互动量异常（如进平台 Top 3）或评论区出现新叙事时，该条可加采到 50 |
| 样本量披露 | 报告与模板中所有占比必须写 `n={N}`；`n<30` 只做定性 |

情绪分类：关键词匹配 + 模型判断；区分「真实负面」与「玩梗调侃」。

## KMI 参考指标库

按本轮数据启用；每个指标输出必须带样本量与采集范围。

| KMI | 计算方式 | 首轮参考阈值 | 预警提示 |
|-----|----------|--------------|----------|
| 正面情绪占比 | 正面评论 / 总采样评论 | >70% 健康；<50% 预警 | 环比降幅 ≥10pp 或绝对 <50% |
| 负面情绪占比 | 负面评论 / 总采样评论 | <15% 健康；>25% 预警 | 环比升幅 ≥10pp 或绝对 >25% |
| 价格焦虑指数 | 价格相关负面 / 总价格评论 | <30% 健康；>50% 预警 | 仅话题含价格讨论时启用 |
| 疲劳指数 | 「挤牙膏/什么时候」类评论增长率 | 稳定或下降 | 连续 3 个观测点增长 |
| KOL 正面率 | 正面 KOL / 已发声 KOL | >70% 健康；<50% 预警 | 顶流 KOL 单独标注 |
| 竞品对比负面率 | 讨论中「竞品更好」/ 对比讨论总数 | <30% 健康；>50% 预警 | 样本不足只列倾向原文 |

示例输出写法：`负面占比 23%（n=186，小红书+抖音评论，2026-09-08~09-10）`。

可按本轮分析逻辑自定义指标，公式与样本量写入报告「本轮分析逻辑」。

## 情绪分类（5 类，评论区）

| 情绪 | 关键词特征 | 示例 |
|------|-----------|------|
| 期待 | 等不及/必买/心动/冲/太香了 | "这配置太香了，等上市" |
| 焦虑 | 价格/什么时候/等太久/挤牙膏 | "到底多少钱，别挤牙膏了" |
| 观望 | 再看看/等等党/对比一下 | "等实车到店再决定" |
| 负面 | 割韭菜/不值/太贵/失望/翻车 | "这价格不如买 {竞品}" |
| 玩梗 | 哈哈哈/笑死/绝了/绷不住 | 调侃向，需与真实负面区分 |

报告汇总层仍用：正面/负面/中性/混合；5 类作为细分写入 `sentiment_detail`。

## KOL 分类框架

| 类型 | 特征 | 典型用途 | 风险 |
|------|------|----------|------|
| 品牌专属型 | 内容高度绑定单一品牌 | 造势/情报释放 | 低 |
| 全品类测评型 | 多品牌横评、重数据 | 口碑/中立背书 | 低 |
| 平台级媒体 | 机构账号、专业团队 | 权威覆盖 | 低 |
| 辣评/观点型 | 争议性观点驱动 | 引爆（双刃剑） | 高 |
| 社区/用户型 | 真实用户或垂直社群 | UGC/证言 | 低 |

## 风险评估矩阵

| 维度 | 问题 | 输出 |
|------|------|------|
| 概率 | 可能性？ | 高/中/低 |
| 影响 | 若发生影响？ | 极高/高/中/低 |
| 触发条件 | 何时触发？ | 具体条件 |
| 预警指标 | 如何提前看到？ | 可量化指标 |
| 应对预案 | 如何响应？ | 时间+动作 |
| 跟踪频率 | 多久看一次？ | 按监测方案 frequency |

## 预测框架

预测数量由本轮逻辑决定，可为 0–N；第 2 轮起默认至少输出「下一轮最可能的变化」。禁止空泛预测。

| 类型 | 方法 | 输出 |
|------|------|------|
| 热点发酵 | 趋势+历史规律 | 结论+触发条件+跟踪指标 |
| 风险演变 | 风险状态+外部变量 | 当前+预测变化+管控动作 |
| 竞品动态 | 竞品历史+行业节奏 | 可能动作+应对预案 |
| 用户行为 | 情绪+决策链路阶段 | 下一步行为+品牌应对 |

## 演变阶段判断

| 阶段 | 数据量 | 情感 | 关键词 |
|------|--------|------|--------|
| 萌芽期 | 缓慢增长 | 中性为主 | 事件描述词 |
| 增长期 | 快速增长 | 开始分化 | 情感词涌现 |
| 爆发期 | 达峰 | 两极化 | 标签化词汇 |
| 衰退期 | 回落 | 趋于一致 | 总结性词汇 |
| 稳定期 | 低水平稳定 | 已定型 | 固定表述 |

### 情感 / 阶段 / 严重度 / 信号类型 / 采集方式

| 类别 | 映射 |
|------|------|
| 情感 | positive→正面，negative→负面，neutral→中性，mixed→混合 |
| 阶段 | emergence→萌芽期，growth→增长期，peak→爆发期，decline→衰退期，stable→稳定期 |
| 严重度 | critical→严重，high→高风险，medium→中等，low→低 |
| 预警级别 | red→红，orange→橙，yellow→黄，blue→蓝 |
| 信号类型 | sentiment_shift→情感转向，keyword_emergence→关键词涌现，volume_spike→热度飙升，narrative_change→叙事变化，risk_trigger→风险触发 |
| 采集方式 | 浏览器控制→浏览器，web_search/websearch→搜索，webfetch→抓取 |

## 信号对象（分析阶段）

信号与预警是两套枚举：

| 用途 | 枚举 | 写入位置 |
|------|------|----------|
| 分析信号（数据怎么变了） | sentiment_shift / keyword_emergence / volume_spike / narrative_change / risk_trigger | research.md `## 信号` |
| 对外预警（要不要动作） | volume_spike / negative_surge / new_keywords / kol_negative / competitor_shift / emotion_turn | 报告预警段 + `## 预警记录` |

常见映射：`sentiment_shift`→`emotion_turn` 或 `negative_surge`；`keyword_emergence`→`new_keywords`；`volume_spike`→`volume_spike`；`narrative_change`→按影响升为预警；`risk_trigger`→按严重度升为红/橙。

```json
  "type": "sentiment_shift|keyword_emergence|volume_spike|narrative_change|risk_trigger",
  "severity": "low|medium|high|critical",

  "recommended_action": "…",
  "risk_assessment": {
    "probability": "high|medium|low",
    "impact": "extremely_high|high|medium|low",
    "trigger_condition": "…",
    "early_warning": "…",
    "response_plan": "…"
  }
}
```
