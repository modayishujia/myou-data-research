# 行业示例（非默认模板）

主文件与模板使用抽象占位符。本文件用**虚构品牌**演示如何填成可用矩阵；调研真实行业时整表替换，不要把示例字段带进无关话题。

## 填空规则

1. 先定场景，再按该场景的 L1–L5 含义填词（见 `scenarios.md`）
2. 每层 1–4 组即可，合计约 5–15 组；冷门话题宁缺毋滥
3. 搜索时优先用「品牌+属性」组合词，避免单独的品牌大词噪音过大

## 产品发布 · 已填示例（虚构户外电源品牌）

| 层 | 类型 | 关键词示例 | 采集目的 |
|----|------|------------|----------|
| L1 | 品牌/产品 | `极光电源 X1`、`极光电源` | 主体声量 |
| L2 | 配置/场景 | `极光电源 X1 容量`、`极光电源 露营`、`极光电源 户外作业` | 讨论焦点 |
| L3 | 竞品 | `极光电源 正浩 对比`、`极光电源 电小二` | 对比热度 |
| L4 | 决策/评价 | `极光电源 价格 值不值`、`极光电源 口碑 缺点` | 购买意图 |
| L5 | KOL | `{垂类KOL名} 极光电源` | 扩散节点 |

对应占位写法：`{产品} {属性词}`、`{产品} {竞品} 对比`。

## 评论区字段按品类裁剪

**价格敏感品类**（汽车、3C、户外电源等）保留：

- 价格预期：用户普遍预期 `{下限}-{上限} 元`（n={N} 条价格相关评论）
- 核心关注点排序示例：容量/续航 → 价格/性价比 → 重量/便携 → 噪音 → 售后

**非价格品类**（内容、政策、B2B 服务等）：

- 省略「价格预期」
- 核心关注点改为该品类的决策要素（如政策话题：影响范围 / 执行时间 / 地方差异）

## 金融单品 · front matter 已填示例（虚构）

```yaml
financial:
  company: "极光科技"
  ticker: "01234.HK"
  product: "极光电源 X1"
  product_line: "便携储能"
  watch_type: single_product
  launch_date: "2026-09-01"
  price_band: "2999-5999"
```

时点字段（每轮采集后追加到话题摘要或数据说明，不塞进 front matter 固定结构）：

- `price_change_pct`：区间涨跌幅
- `delivery_latest`：最新交付/销量
- `consensus`：市场预期

缺失任一项 → 在「数据说明 · 已知缺口」标注，并降级为「社媒单品信号」。
